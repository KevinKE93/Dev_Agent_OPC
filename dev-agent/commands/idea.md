---
description: Refine a rough idea into a focused product or engineering brief
---

Invoke the `idea-refine` skill.

Turn the rough request into a project brief before writing specs or code:

1. Identify target users, jobs to be done, and the concrete outcome.
2. Preserve a lightweight requirement attribution table: user-stated inputs, agent inferences, product decisions, and open confirmations.
3. Separate must-have scope from optional exploration.
4. Capture constraints, non-goals, risks, and open questions.
5. For customer-facing apps, ask for reference images, reference software, links, screenshots, or Figma files when visual direction is not already delegated.
6. Save the result under `<project-name>/dev-agent/ideas/idea-brief.md`.

Do not jump to implementation from this phase.
